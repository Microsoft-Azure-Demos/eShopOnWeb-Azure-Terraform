# Bootstrapping Terraform Remote State Infrastructure

## Overview

Before Terraform can use Azure Blob Storage as a remote backend, the required Azure resources must exist.

The `bootstrap/` configuration creates the infrastructure needed to store and manage Terraform remote state.

It provisions:

- **Resource Group:** Hosts the remote state resources.
- **Storage Account:** Provides Azure Blob Storage for Terraform state.
- **Blob Container:** Stores Terraform state files with private access.
- **Role Assignment:** Grants the currently authenticated Azure identity the `Storage Blob Data Contributor` role, allowing it to read and write state blobs.

The configuration also uses the Azure Naming module to generate compliant resource names.

## Directory Structure

```text
bootstrap/
├── main.tf
├── variables.tf
├── locals.tf
├── outputs.tf
└── providers.tf
```

## Prerequisites

- Azure CLI installed.
- Terraform installed.
- An authenticated Azure CLI session.
- Sufficient Azure permissions to create resources and assign RBAC roles.

Authenticate with Azure:

```powershell
az login
```

If necessary, select the correct subscription:

```powershell
az account set --subscription "<SUBSCRIPTION_ID>"
```

## Deploy the Bootstrap Infrastructure

Run the following commands from the `bootstrap/` directory.

**1. Initialize Terraform**

```powershell
terraform init
```

**2. Review the deployment plan**

```powershell
terraform plan
```

**3. Create the Azure resources**

```powershell
terraform apply
```

Confirm the deployment when prompted.

## Configure the Remote Backend

After the bootstrap deployment completes, retrieve the generated Storage Account name, Resource Group name, and Blob Container name from the Terraform outputs.

Use these values to configure `backend.hcl` in the respective Terraform environment directories.

Example:

```hcl
resource_group_name  = "<RESOURCE_GROUP_NAME>"
storage_account_name = "<STORAGE_ACCOUNT_NAME>"
container_name       = "<CONTAINER_NAME>"
key                  = "eshop-infrastructure.tfstate"
```

Initialize the infrastructure configuration using:

```powershell
terraform init -backend-config="backend.hcl"
```

## Important Notes

- Bootstrap infrastructure must be deployed before initializing the remote backend.
- The bootstrap configuration uses local Terraform state by default. Keep its state file secure and backed up.
- Do not destroy the bootstrap resources while other Terraform configurations depend on the remote state stored in the Storage Account.
- The `Storage Blob Data Contributor` role assignment allows the authenticated identity to manage blobs. RBAC role assignments may take a few minutes to become effective.

Once bootstrap is complete, the other Terraform configurations can use Azure Blob Storage for remote state management.
